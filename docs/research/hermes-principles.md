# Hermes-derived principles

Accessed 2026-07-31. QueueProof adopts architectural principles, not source code, branding, or trade dress:

- a shared core usable by UI, CLI, and agents;
- a narrow authenticated gateway;
- bounded provenance-aware memory classes;
- progressively disclosed, portable skills;
- a controlled improvement loop that proposes tested diffs and requires approval.

These ideas are expressed in original QueueProof contracts and the Circuit Shrine interface. Production skills are never self-replaced.
