# 60-second demo script

**0–6s — Problem.** “The same incident is fragmented across Slack, Linear, GitHub, Gmail and documents. Search returns snippets; teams still cannot defend what to do next.”

**6–14s — Proof boundary.** Open Evidence. Show the three-provider proof rail plus the measured 346-page PDF receipt. “A connector is unusable until HydraDB returns real records and QueueProof stores a proof receipt.”

**14–31s — Flagship.** Open Proof and run: “Who escalated the AuthShield outage, what did engineering commit to, and is the fix already merged?” While it runs, point to auto routing. On return, call out three-provider coverage, one HydraDB call and latency.

**31–42s — Inspectability.** Reveal the inline citations and preserved disagreement, then open a citation receipt drawer. Copy its ID. “No unsupported prose is allowed into this answer.”

**42–50s — Decision.** Open Queue, sort by priority, then open the top packet. Show the exact six-factor score formula, penalties, deduplicated source tasks and safe next action.

**50–57s — Receipt.** Open the retrieval receipt and Benchmarks. Point to routing reason, graph flag, cost units, p50/p95 latency and calls. “The evidence and the cost are inspectable together.”

**57–60s — Close.** “QueueProof makes the answer—and the action—provable. Live product and reproducible GitHub benchmark are ready now.” Show the live and GitHub links.
