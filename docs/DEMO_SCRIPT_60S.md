# 60-second demo script

**0–7s — Problem.** “The same incident is fragmented across Slack, Linear, GitHub, Gmail and documents. Search returns snippets; teams still cannot defend what to do next.”

**7–16s — Proof boundary.** Open Evidence. Show real provider icons, verified state, database scope and canary record counts. “A connector is unusable until HydraDB returns real records and QueueProof stores a proof receipt.”

**16–31s — Flagship.** Open Proof and run: “Who escalated the AuthShield outage, what did engineering commit to, and is the fix already merged?” While it runs, point to auto routing. On return, call out three-provider coverage, one HydraDB call, latency, cited claims and the preserved disagreement.

**31–41s — Inspectability.** Open a citation receipt drawer. Copy its ID. Point to the routing reason, graph flag and cost units. “No unsupported prose is allowed into this answer.”

**41–51s — Decision.** Open Queue, sort by priority, then open the top packet. Show the exact six-factor score formula, penalties, deduplicated source tasks, receipt hash and safe next action.

**51–57s — Control.** Send the packet to Approvals. “Agents can propose this exact payload; no provider write occurs until a human reviews it, and idempotency blocks double execution.”

**57–60s — Close.** Open Benchmarks. “39 labelled cases, real live latency and calls, plus a 346-page adversarial PDF benchmark. QueueProof makes the answer—and the action—provable.”
