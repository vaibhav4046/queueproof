# Social copy

## LinkedIn

Agents know how to execute. The harder question is what deserves execution next—and whether anyone can prove why.

QueueProof is a priority and execution control plane built around HydraDB. It connects live work systems, retrieves cited evidence, ranks candidate work with a deterministic policy, and gives people or MCP agents a bounded Execution Packet. Connector state is proven with sync and canary evidence; actions remain proposals until approval.

Tagline: **A defensible next action—with receipts.**

Live connector proof will be added only after scoped test accounts are authorised; the current build intentionally shows an honest disconnected state.
