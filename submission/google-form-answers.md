## Product
QueueProof: Agent Priority and Execution Control Plane.

## One-line description
QueueProof turns fragmented live work evidence into a deterministic, cited next action for people and MCP agents.

## HydraDB usage
QueueProof dynamically loads connector/provider contracts, discovers resources, requests sync, verifies source presence with a canary query, and uses fast/thinking retrieval with graph context. Provider attribution, source timestamps, request IDs, and latency are retained in the proof trace.

## What is technically distinctive
Connection is treated as a multi-stage proof protocol; ranking is versioned and deterministic; source content is an untrusted evidence plane; and agent writes are separated into proposal, approval, execution, and verification.
