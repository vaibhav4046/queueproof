# Sixty-second demo script

This script may be recorded only after Slack, Gmail, and Linear show real `data_verified` receipts and private data has been redacted.

- **0–7s:** Open Command. “Your agents already know how to execute. The missing layer is deciding what deserves execution.”
- **7–18s:** Ask “What should I do next, and why?” Keep the live retrieval trace visible.
- **18–32s:** Open the top real queue item and its three-provider Proof Packet.
- **32–42s:** Compare number one and two; show component deltas and one counterfactual.
- **42–50s:** Open a real untracked commitment and create a Linear issue proposal. Do not execute without approval.
- **50–56s:** Open Agent Dock and invoke QueueProof from a verified MCP client.
- **56–60s:** Show live evaluation accuracy, latency, calls, and mode. “QueueProof gives every person and every agent a defensible next action—with receipts.”
